# Circadian Pro working procedure

The project owner has requested that completed, validated updates are also
published to GitHub as the normal workflow. Follow `docs/releasing.md` when
finishing an update: keep `main`, the version tag and the release ZIP aligned.
Do not leave a completed release only on a development branch.

Keep backups before Home Assistant updates and preserve existing profile
configuration, calibrations, entity identifiers and switch states. Report what
was verified locally, in CI and in Home Assistant separately.
