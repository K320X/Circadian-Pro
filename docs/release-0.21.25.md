# Circadian Pro 0.21.25

The profile list now places the shorter Sort label beside its dropdown. Row configuration buttons shrink from 44 to 40 px, with 20 px fader icons. The mobile sidebar button uses three plain bars in the theme's text color without a permanent frame, retaining its 48 px touch area and keyboard focus outline.

Sorting, configuration navigation, sidebar events and all stored settings remain unchanged. Validation covers the existing frontend regression suite and visual inspection at desktop and mobile widths, including a narrow 320 px viewport. Exact-revision CI and Home Assistant installation checks are recorded separately.
