# Circadian Pro 0.21.23

The 1–100 brightness range now follows its label with an 8 px gap instead of aligning to the far edge of the field. This applies to desktop and mobile without changing field limits, configuration or light-control behavior.

The release procedure now retains the active installation and two previous verified recovery versions, pruning older Circadian Pro deployment artifacts only after the new installation is validated. GitHub source and published release history remain intact.

Validation covers the existing JavaScript regression suite, source checks, exact-revision CI and desktop/mobile inspection. Installation and cleanup evidence is recorded separately.
